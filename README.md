An interactive, multi-page educational web application that visually explains CPU scheduling algorithms — making complex Operating System concepts accessible and engaging for every learner.

---

## What is this project?

CPU scheduling is one of the most important — and most confusing — topics in Operating Systems. This project breaks it down visually, step by step, so that students can *see* how each algorithm works instead of just reading about it.

Built by a learner, for learners.

---

## Algorithms Covered

| Algorithm | Full Name |
|-----------|-----------|
| FCFS | First Come First Served |
| SJF | Shortest Job First |
| HRRN | Highest Response Ratio Next |
| *(more)* | Additional algorithms included |

## Pages & Features

### Home Page
A clean landing page with four dedicated sections:

- **Acknowledgements** — Credits and inspiration behind the project
- **Source Code** — Direct access to the project's codebase
- **Video Resources** — Curated YouTube videos in both Hindi and English for deeper understanding
- **Reading Materials** — Articles and notes to supplement the visual learning

### Algorithm Visualizer Pages
Each algorithm has its own dedicated page with:
- Step-by-step visual explanation
- Easy-to-follow UI designed for students

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/TargetUltimate-Alka/CPU-Scheduling-Algorithm.git
   ```

2. Navigate into the project folder:
   ```bash
   cd CPU-Scheduling-Algorithm
   ```

3. Open `index.html` in your browser — no installation or setup needed.

## Why I Built This

I come from a mathematics and education background, and I've always believed that the best way to understand something is to *see* it. When I started learning about CPU scheduling algorithms, I noticed most resources were either too dry or too technical for beginners.

So I built this — a visual, bilingual-friendly learning tool that bridges computer science concepts with accessible, student-first design.

This project sits at the intersection of two things I care deeply about: **technology** and **education**.
